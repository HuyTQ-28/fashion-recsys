# Model Summary: FREEDOM (ACM MM 2023)

## Core Philosophy
* **Problem:** Previous state-of-the-art models like LATTICE dynamically learn latent item-item graphs, which poses a prohibitive quadratic computational cost ($O(N^2d_m)$) and is ultimately unnecessary.
* **Solution:** FREEDOM introduces a highly efficient architecture that simultaneously **freezes** the item-item graph and **denoises** the user-item interaction graph for multimodal recommendation.

## Graph Construction Process

### 1. Frozen Item-Item Graph
* **Similarity Computation:** The model computes the cosine similarity $S_{ij}^m$ between items using their raw multimodal features, such as visual and textual data.
* **kNN Sparsification:** To create a discrete and unweighted matrix, FREEDOM applies kNN sparsification, retaining only the top-k similar edges for each item (empirically fixed at $k=10$).
* **Modality Fusion:** The normalized modality-aware adjacency matrices are aggregated into a single latent item-item graph using the equation: $S = \alpha_v \tilde{S}^v + (1 - \alpha_v) \tilde{S}^t$.
* **Freezing Strategy:** This fused item-item graph is pre-calculated and frozen during model training, which completely removes the $O(N^2d_m)$ computational burden associated with dynamic graph construction.

### 2. Denoised User-Item Graph
* **Degree-Sensitive Edge Pruning:** To counteract over-smoothing and mitigate noise from unintentional user interactions (false-positives), FREEDOM applies a degree-sensitive pruning technique to the user-item graph.
* **Sampling Probability:** Edges are sampled based on a multinomial distribution where the probability $p_k$ of an edge is calculated as $p_k = \frac{1}{\sqrt{\omega_i}\sqrt{\omega_j}}$, with $\omega$ representing the node degrees. Consequently, edges connecting high-degree (popular) nodes have a lower probability of being sampled and are more likely to be pruned.
* **Dynamic vs. Static:** This pruning and re-normalization occurs iteratively at each training epoch; however, the model reverts to using the original, un-pruned normalized adjacency matrix during inference.

## Training and Inference
* **Message Passing:** FREEDOM utilizes a light-weighted Graph Convolutional Network (LightGCN) to propagate and aggregate embeddings across both the frozen item-item graph and the denoised user-item graph.
* **Final Representations:**
    * The user's final representation ($h_u$) is derived entirely from the output of the user-item graph.
    * The item's final representation ($h_i$) is the sum of the representations extracted from both the item-item graph ($\tilde{h}_i$) and the user-item graph ($\hat{h}_i$).
* **Optimization:** The model is optimized using a pairwise Bayesian Personalized Ranking (BPR) loss, combined with a hyperparameter-weighted ($\lambda$) reconstruction loss that aligns projected multimodal features from MLPs into the same latent space as the ID embeddings.
* **Top-K Inference:** Recommendations are generated by calculating the interaction score via a dot product of the final ID embeddings: $r(h_u, h_i) = h_u^\top h_i$. Projected item multimodal features are excluded from this prediction calculation.
